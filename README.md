# بنّاء APK

تطبيق أندرويد (Flutter) يجمّع مشاريعك إلى APK عبر **GitHub Actions** دون أن تدخل إلى GitHub.

## كيف يعمل

1. **تسجيل الدخول (مرة واحدة فقط):** يظهر كود تحقق، تدخله في `github.com/login/device`، فيُحفظ التوكن مشفّراً على الجهاز.
2. **مشروع جديد:** تكتب الاسم فيُنشأ مستودع **خاص** بهذا الاسم في حسابك.
3. **اختيار ملف ZIP:** يرفع التطبيق الملف إلى المستودع، وينشئ ملف workflow يفك الضغط ويجمّع، ثم يشغّله.
4. **المتابعة:** شريط تقدّم + صندوق يعرض خطوات التجميع لحظة بلحظة.
5. **النتيجة:** عند النجاح يُنزَّل ملف APK ويظهر زر «تثبيت»، وعند الفشل يظهر سبب الخطأ وآخر سطور السجل.

المشاريع المدعومة داخل ملف ZIP:
- **Flutter** (يوجد `pubspec.yaml`). إن لم يكن مجلد `android` موجوداً يُنشأ تلقائياً.
- **Android أصلي** (Gradle). يُبنى بـ `assembleDebug`.

يمكن أن يكون المشروع في جذر الـ ZIP أو داخل مجلد واحد في الجذر.

---

## الخطوة 1: إنشاء OAuth App (مرة واحدة)

1. GitHub ← Settings ← Developer settings ← OAuth Apps ← **New OAuth App**.
2. الاسم: أي اسم. Homepage URL و Callback URL: ضع `https://github.com` في الحقلين.
3. بعد الإنشاء فعّل الخيار **Enable Device Flow** واحفظ.
4. انسخ **Client ID** (ليس سرّاً، ويمكن وضعه داخل التطبيق).

## الخطوة 2: بناء التطبيق نفسه

### الطريقة أ: رفع ملفات المشروع مباشرة
1. أنشئ مستودعاً جديداً وارفع إليه **محتويات** هذا المجلد (بما فيها المجلد المخفي `.github`).
2. (اختياري) Settings ← Secrets and variables ← Actions ← Variables ← أضف متغيراً باسم `GH_CLIENT_ID` وقيمته الـ Client ID. وإن تركته فسيطلبه التطبيق عند أول تشغيل.
3. تبويب **Actions** ← **Build APK Builder app** ← Run workflow.
4. بعد انتهاء التجميع حمّل الملف من **Releases** (الأسهل من الجوال) أو من Artifacts.

### الطريقة ب: من الجوال بدون رفع مجلدات
1. أنشئ مستودعاً جديداً.
2. ارفع ملف هذا المشروع المضغوط باسم **`project.zip`** في جذر المستودع.
3. أنشئ الملف `.github/workflows/build-apk.yml` وضع فيه محتوى `bootstrap/build-apk.yml`.
4. Actions ← **Build APK** ← Run workflow. (هذا هو نفس الـ workflow الذي سيستخدمه التطبيق لاحقاً.)

## الخطوة 3: الاستخدام

1. ثبّت الـ APK. عند أول تثبيت قد يطلب أندرويد السماح بـ «تثبيت تطبيقات من هذا المصدر».
2. سجّل الدخول بالكود (وأدخل Client ID إن لم تضعه وقت البناء).
3. **مشروع جديد** ← اكتب الاسم ← اختر ZIP ← انتظر النتيجة.

## ملاحظات وحدود

- **الخصوصية والحصة:** المستودعات تُنشأ **خاصة**. الحسابات المجانية لها 2000 دقيقة Actions شهرياً، وبناء Flutter يستغرق عادةً 5 إلى 10 دقائق.
- **حجم ZIP:** حتى 50MB (حدّ واجهة GitHub لرفع الملفات 100MB).
- **التوقيع:** ملف APK الناتج موقّع بمفتاح debug، مناسب للتجربة والتثبيت المباشر وغير مناسب للنشر على Google Play.
- **الصلاحيات:** يطلب التطبيق صلاحيتي `repo` و `workflow` ليتمكن من إنشاء المستودع ورفع الملفات.
- **إبقاء التطبيق مفتوحاً:** المتابعة تتم أثناء فتح شاشة المشروع. لو خرجت منها يستمر التجميع على GitHub، وتجد نتيجته لاحقاً بزر «عرض نتيجة آخر تجميع».
- **البنية:** `lib/services/github_api.dart` (طلبات GitHub)، `build_controller.dart` (رحلة التجميع)، `workflow_template.dart` (الـ workflow المرفوع، مولَّد من `bootstrap/build-apk.yml`).
